# Папка для скриншотов Sola Scriptura

Файлы в этой папке отображаются в [**`README_RELEASES.md`**](../../README_RELEASES.md):

1. **`reader-preview.png`** — Главный экран программы: чистый режим чтения Священного Писания с типографикой и панелью навигации.
2. **`parallel-preview.png`** — Параллельное чтение переводов (сравнение текстов в двух синхронных колонках).
3. **`commentary-preview.png`** — Панель классических толкований и комментариев (Лопухин, МакАртур, Баркли, святоотеческие и исторические комментарии).
4. **`search-preview.png`** — Быстрый переход и мгновенный поиск (`Ctrl + K`).
5. **`strong-preview.png`** — Карточка словаря Стронга: оригинальный корень слова (древнегреческий / древнееврейский), транслитерация и словарное определение.
6. **`strong-occurrences-preview.png`** — Симфония номеров Стронга: просмотр всех стихов и вхождений оригинального слова по всей Библии.
7. **`hebrew-preview.png`** — Языки оригинала: чтение Танаха на древнееврейском языке с огласовками параллельно с Синодальным переводом.

### Стиль оформления
Все скриншоты для витрины оформлены в виде парящего окна программы с мягкими скругленными углами (`border-radius: 18px`), деликатной светлой каймой (`1.2px`) и мягкой лёгкой тенью (`10px` blur, `5px` drop) на фоне исторической картины эпохи Реформации («Возвращение Жана Кальвина в Женеву»). Окно сбалансировано по пропорции 3:2, сохраняя целостность композиции картины, и полностью очищено от элементов панели задач Windows.
